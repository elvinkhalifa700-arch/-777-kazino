777 KAZINO — MOBİL VIRTUAL DEMO
================================

Bu layihə yalnız pulsuz, virtual əyləncə prototipidir.
- Ödəniş, kartdan-karta köçürmə və ödəniş təsdiqi YOXDUR.
- Mərc, pul uduşu, nağdlaşdırma və real pul hesablaşması YOXDUR.
- AZN yazısı yalnız şərti demo göstəricisidir; pul balansı deyil.
- Slot fırlatmaları pulsuzdur və balansı dəyişmir.

Quraşdırma:
1. Kompüterdə Node.js 20 və ya daha yeni versiya quraşdırın.
2. Bu qovluqda terminal açın və `npm install` yazın.
3. `.env.example` faylının surətini `.env` adı ilə yaradın.
4. `.env` daxilində SESSION_SECRET üçün uzun təsadüfi mətn və ADMIN_PASSWORD üçün güclü şifrə yazın.
5. `npm start` işlədin.
6. Brauzerdə http://localhost:3000 açın.

Məlumatlar 777-kazino.sqlite faylında saxlanır.
Admin panelindən yeni müştəri kodu yarada və virtual demo göstəricisini təyin edə bilərsiniz.

Vacib:
Bu paket hazır serverdə yerləşdirilmiş sayt deyil. İnternetdə daimi işləməsi üçün HTTPS dəstəkləyən hostinq, mühit dəyişənlərinin təhlükəsiz qurulması və istehsal üçün uyğun sessiya saxlanması tələb olunur. İctimai istifadəyə çıxarmadan əvvəl texniki təhlükəsizlik yoxlaması etdirin.
